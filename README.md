# Elevora – Career Development Platform

Elevora is a responsive career development platform designed to help students and beginners organize their learning journey and prepare for their careers.

## Live Demo
https://samriddhi-katakdhond.github.io/Elevora/

## Features
- Responsive user interface.
- Interactive feature cards.
- Skill Tracker to add new skills.
- Mark skills as completed.
- Delete skills from the tracker.
- Local Storage to save skills even after refreshing the page.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage
- Git & GitHub

## Project Structure
- index.html
- CSS/style.css
- JS/script.js

## Purpose
The purpose of Elevora is to provide a simple platform for students to organize their learning goals and track their skill development progress.
